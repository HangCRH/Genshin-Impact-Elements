# 语言 language
本模组支持简体中文、美式英语。此处为中文简介，英语简介位于[README.md](README.md)。<br>
This mod supports Simplified Chinese and American English. The Chinese introduction is provided here, while the English introduction can be found in [README.md](README.md).
# 简介
本模组添加了《原神》中的七种元素，使用附魔书或处于特定环境均可触发元素反应。元素反应可造成各种特殊效果，或对单次攻击提供伤害加成。
# 元素附魔
元素附魔用于武器，附魔元素的武器打出的伤害就从物理伤害变为元素伤害。<br>
元素附魔可以在附魔台中获得，也可以在结构的宝箱中获得。

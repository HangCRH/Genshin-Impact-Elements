# Introduction
This mod adds the seven elements from Genshin Impact. Elemental reactions can be triggered by using enchanted books or by being in specific environments. Elemental reactions can cause various special effects or provide damage bonuses for a single attack.

# Elemental Enchantment
Elemental enchantments are applied to weapons. A weapon enchanted with an element will convert its damage from physical to elemental damage.<br>
Elemental enchantments can be obtained from an enchanting table or found in chests within structures.
